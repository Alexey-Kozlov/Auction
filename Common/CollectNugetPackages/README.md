Утилита для копирования всех необходимых для сборки образов nuget-пакетов в указанную папку.

Для чего - чтобы при создании докер-образа не нужно было лезть в интернет за нужными Nuget-пакетами
Вместо этого все пакеты будут забирвться из папки, указангой в конфиге "TargetNugetPath"

Использование - просто запускаем на выполнение.
Будет очищена папка назначения и туда скопированы nuget-пакеты из кеша.
В кеше nuget-пакеты накапливаются при отладке приложений.

После запуска приложения - будет показано количество скопированных из кеша пакетов.
